# Nonlocal heat-flux closure across collision models

A 54-page research manuscript synthesized from the plasma-closure notes in the parent
directory, with a unified physical energy-flux convention, proofs, primary
references, and reproducible numerical evidence. The original notes are unchanged.

- [Read the paper](output/pdf/manuscript.pdf).
- [Editable LaTeX source](manuscript.tex) and [bibliography](references.bib).
- [Source and mathematical audit](SOURCE_AUDIT.md).
- [Validation record](VALIDATION.md) and [original plan](PLAN.md).
- [Configuration](config.json) and [fresh-computation metrics](results/2026-11-17-fresh/metrics.json).

The paper studies linear, quasi-static heat-flux responses to two drives.
For a potential force it develops variational bounds, explicit BGK and
Dougherty responses, and three-dimensional Landau stress corrections; an
embedded initial-value experiment tests the limits of using this response as
a transient closure. For an isotropic heating source (Sections 7, 8 and 10,
merged from the [extension note](../electron_heat_flux_extension/README.md))
it proves all-wavenumber bounds without momentum conservation and applies
them to electron-electron plus electron-ion collisions. The thermally driven
response is a Stieltjes function of `k^2` (Section 7.6): monotone, with a
positive real-space kernel that is a mixture of exponentials, and with
two-sided Pade bounds. At large ion charge (Section 8.1, Appendix E) the
normalized deficit is proved to grow linearly in `Z`, with slope
`C_inf/kappa_L = 1.4305`, and the response converges to a radial diffusive
limit with two-sided bounds.
The Landau collisionless boundary-layer conclusion is explicitly conditional,
and the electron results assume form-domain solvability.
The manuscript has no assigned authors; authorship can be added before circulation
or submission.

## Reproduce

Run these commands from this directory in a checkout of the full repository.
Python 3.13 was used; exact numerical dependencies are in `requirements.txt`.
The scripts also use the existing modules in `../../scripts/landau_closure/`.
They do not import any of the three independent project packages.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m unittest -v test_numerics.py
.venv/bin/python reproduce.py --output results/my-run --rebuild-landau
.venv/bin/python extra_checks.py results/my-run/metrics.json --output results/my-run/verification.json
.venv/bin/python make_figures.py results/my-run/metrics.json
```

Choose a new run directory each time. The computation refuses to overwrite an
existing run; extra checks also refuse to overwrite their output. The full
fresh-matrix calculation took approximately 262 seconds on the recorded host.
Omit `--rebuild-landau` only to reuse locally available matrices; their hashes
are then recorded. A missing cache is rebuilt automatically. No matrix cache
is required for a clean reproduction. Random sampling is not used; seed 0 is
nevertheless recorded. Each run saves the configuration, environment, source
hashes, diagnostics, runtime, status, and any failure in `metrics.json`.

The optional `--compare-metrics results/2026-11-17/metrics.json` argument to
`response_matrix.py` computes the like-particle response matrix of Table 8
(`config_matrix.json`, `results/2026-11-18-matrix/`); see `VALIDATION.md`.
`stieltjes_check.py` tests the sign conditions of Section 7.6 at complex
`k^2` and the Pade bounds (`config_stieltjes.json`,
`results/2026-11-18-stieltjes/`, under one second, cached Landau matrices).
`large_z.py` solves the radial limit problem of Section 8.1 with an
independent radial discretization of the Landau form, cross-checks it
against the cached matrices, and compares with the three-dimensional
electron computation (`config_large_z.json`, `results/2026-11-18-largez/`,
under one second); its `figures` subcommand writes Table 9 and Figure 5.
`extra_airy_check.py` checks the boundary-layer profile identities of
Appendix D by quadrature and prints the residuals (about nine minutes).
`extra_checks.py` compares transport constants against the archived cache-based
run. Optional cache-symmetry checks are reported as skipped when caches are absent.

## Build the paper

The generated figures and table fragments are included, so a PDF build does not
require rerunning the calculations. Install a TeX distribution with `latexmk`,
BibTeX, `newtx`, `microtype`, `natbib`, and `cleveref`, then run:

```sh
mkdir -p tmp/latex output/pdf
latexmk -pdf -interaction=nonstopmode -halt-on-error -outdir=tmp/latex manuscript.tex
cp tmp/latex/manuscript.pdf output/pdf/manuscript.pdf
```

The three figures and four numerical tables of Sections 1-9 are generated by
`make_figures.py` from the saved metrics. The two figures and four tables of
Section 10 are read directly from `../electron_heat_flux_extension/figures/`,
where that directory's `make_figures.py` generates them from its own saved
metrics; they are not copied here, so the build needs the neighboring
directory. In the first group, exact analytic constants in the comparison table are
typeset symbolically. `figures/provenance.json` identifies the run used for the
delivered paper. `source_manifest.json` records hashes of the source notes and
the manuscript bundle at delivery.

The reported Galerkin differences are refinement diagnostics, not certified
continuum error bars. Ensemble-estimation and learned-model errors are not
applicable to these deterministic, untrained calculations. The paper reports
transient closure error separately from velocity truncation, quadrature, and
asymptotic-expansion error.
